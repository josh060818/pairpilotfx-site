# PairPilotFX public site

Minimal public website for PairPilotFX branding and Google/YouTube OAuth compliance.

## Public pages

- `/` — PairPilotFX homepage
- `/privacy/` — Privacy Policy
- `/terms/` — Terms of Service

## Custom domain

The repository includes:

```text
CNAME
pairpilotfx.com
```

Once GitHub Pages is enabled for the `main` branch and DNS is pointed to GitHub Pages, the intended URLs are:

- https://pairpilotfx.com/
- https://pairpilotfx.com/privacy/
- https://pairpilotfx.com/terms/

## Google OAuth branding values

Use these URLs in Google Auth Platform → Branding:

```text
Application home page:
https://pairpilotfx.com/

Application privacy policy link:
https://pairpilotfx.com/privacy/

Application terms of service link:
https://pairpilotfx.com/terms/

Authorized domain:
pairpilotfx.com
```

## Maintenance

Review the Privacy Policy and Terms whenever PairPilotFX changes its OAuth scopes, data handling, public account features, hosting, or business model.
